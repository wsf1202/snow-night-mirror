# Style-locked publish hosts

One Cursor `publish-app` project per art style (never a combined chip site).

| Folder | Style lock | Suggested slug |
|--------|------------|----------------|
| `hosts/vintage` | vintage postcard | `snow-night-vintage` |
| `hosts/paper` | paper craft | `snow-night-paper` |
| `hosts/neon` | neon | `snow-night-neon` |

Each folder is a self-contained Vite app with `base: '/'` for Cursor hosting.
Pixel remains the existing kept publish / main tree.
